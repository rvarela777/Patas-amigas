# Patas Amigas
 
## Apresentação do Projeto
 
Projeto desenvolvido para a ONG Patas Amigas, com o objetivo de apresentar a organização, seus projetos e disponibilizar uma área de cadastro.
 
## Tecnologias Utilizadas
 
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
 
## Estrutura do Projeto
 
- CSS
- JS
- Imagens
- index.html
- projetos.html
- cadastro.html
 
## Funcionalidades
 
- Navegação SPA
- Validação de formulário
- Persistência de dados com localStorage
 
## Instalação e Execução
 
1. Clonar ou descarregar o repositório.
2. Abrir a pasta do projeto.
3. Executar o ficheiro index.html num navegador.
 
## Versionamento
 
O projeto utiliza Git e GitHub para controlo de versões.
 
Branches utilizadas:
 
- master
- develop
- feature/spa
- feature/validacao
- feature/localstorage
